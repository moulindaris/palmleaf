📡 REST API Endpoint Documentation

Base URL: http://localhost:5000

POST /api/process

Executes full AI pipeline: image upload → OpenCV pre-processing → U-Net restoration → Tesseract OCR → text cleaning → stroke classification → knowledge extraction → database storage.

Form Data Parameters: 
image     : (file) manuscript image file (PNG/JPG/BMP/TIFF)
title     : (string) manuscript title
location  : (string) discovery site location
latitude  : (float, optional) GPS latitude
longitude : (float, optional) GPS longitude
JSON Response Payload: 
{
  "id": 1,
  "original": "data:image/png;base64,...",
  "preprocessed": "data:image/png;base64,...",
  "restored": "data:image/png;base64,...",
  "raw_text": "...",
  "clean_text": "...",
  "text_diff": { "raw_chars": 120, "clean_chars": 95, "removed_chars": 25, "raw_lines": 5, "clean_lines": 4 },
  "classification": { "style": "Dense Script", "period": "Chola (9th–13th Century CE)", "confidence": 0.88 },
  "knowledge": { "category": "Medicine", "dynasty": "Chola", "period": "9th–13th Century CE", "tags": [...] }
}
GET /api/manuscript/<id>

Retrieve full manuscript record by unique ID, including linked artifacts and knowledge tags.

GET /api/manuscript/1
GET /api/search?q=&category=&dynasty=

Search catalog by Tamil text keywords, manuscript title, category, or dynasty filters.

GET /api/search?q=மருந்து&category=Medicine&dynasty=Chola
GET /api/analytics

Returns quantitative statistical metrics grouped by category, dynasty, and historical period.

{ "total": 32, "by_category": [...], "by_dynasty": [...], "by_period": [...] }
GET /api/locations

Returns manuscript discovery sites with GPS latitude/longitude for Leaflet map rendering.

[{ "id": 1, "title": "...", "location": "...", "latitude": 10.7870, "longitude": 79.1378, "category": "Medicine" }]
