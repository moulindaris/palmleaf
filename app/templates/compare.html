How to read language and script relationships

Languages are not scripts. A script can be adapted by several languages, and two scripts sharing an ancestor does not mean their languages descend from one another. The repository’s current classifier label (for example, a subject category or visual-style heuristic) does not identify a historical script such as Tamil-Brahmi or Grantha.

So this comparison only reports record-backed similarities. It will not claim a language lineage from a manuscript title, dynasty, or visual style.

Reference context

  • Tamil Nadu Archaeology: Tamil-Brahmi — regional script evidence and Tamil-Brahmi inscriptions.
  • Tamil Nadu Archaeology: Tamil script inscriptions — an institutional overview of script history.
  • Tamil Nadu Archaeology: Grantha inscriptions — Grantha is a script used for Sanskrit, not a language family.
  • Columbia University: Sinhala — Sinhala is Indo-Aryan; its language family is distinct from its writing system.
  • SOAS: Evolution of the Sinhalese script — study of the historical script, separate from language genealogy.

Automatic historical-script recognition would need labeled manuscript images and a trained model. Recording sourced language and script fields allows repository comparisons without ML; a lineage claim still needs historical evidence.
